Instrucciones para Gmail (App Password):
  1. Activa la verificación en 2 pasos en tu cuenta Google.
  2. Ve a Mi cuenta → Seguridad → Contraseñas de aplicación.
  3. Crea una contraseña para "Correo" (o "Otro — nombre personalizado").
  4. Copia los 16 caracteres generados y úsalos como Contraseña aquí.
  5. Usa smtp.gmail.com, puerto 587 y tu dirección Gmail como usuario.
587 para STARTTLS (recomendado) · 465 para SSL
Si ya hay una contraseña guardada se muestra como *****. Déjala así para no cambiarla.
Si se deja vacío se usará el usuario como remitente.
