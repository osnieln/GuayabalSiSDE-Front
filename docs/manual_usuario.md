## 1. Introducción

El **SGPA** (Sistema de Gestión de la Producción Agrícola) es una aplicación web desarrollada para la granja "El Guayabal" que permite administrar de forma centralizada las áreas de cultivo, la producción, el riego, el uso de agroquímicos y la generación de reportes.

---

## 2. Acceso al sistema

Para ingresar al sistema, el usuario debe abrir el navegador web y acceder a la URL del servidor donde esté desplegado el SGPA.

![Pantalla de inicio de sesión](imagenes/login.png)

**Pasos para autenticarse:**

1. Ingresar el **Usuario** en el primer campo de texto.
2. Ingresar la **Contraseña** en el segundo campo.
3. Presionar el botón **Autenticar**.

> Si las credenciales son incorrectas, el sistema mostrará un mensaje de error. Contacte al administrador del sistema si no recuerda sus datos de acceso.

---

## 3. Panel principal (Dashboard)

Una vez autenticado correctamente, el sistema redirige al **panel principal**, donde se presenta un resumen del estado actual de la granja.

![Panel principal](imagenes/dashboard.png)

## 4. Gestión de Áreas

Esta sección permite administrar las áreas físicas de la granja.

![Gestión de áreas](imagenes/areas.png)

**Acciones disponibles:**

| Acción | Descripción |
|--------|-------------|
| Agregar | Registra una nueva área en el sistema |
| Editar | Modifica los datos de un área existente |
| Eliminar | Elimina un área del sistema |

---

## 5. Gestión de Cultivos

Permite registrar y administrar los cultivos disponibles en la granja.

![Gestión de cultivos](imagenes/cultivos.png)

**Acciones disponibles:**

| Acción | Descripción |
|--------|-------------|
| Agregar | Registra un nuevo cultivo |
| Editar | Modifica los datos de un cultivo existente |
| Eliminar | Elimina un cultivo del sistema |

---

## 6. Gestión de Tipos de Cultivo

Permite clasificar los cultivos por tipo (ej. permanente, temporal, etc.).

![Gestión de tipos de cultivo](imagenes/tipo_cultivo.png)

![Gestión de área-cultivo](imagenes/area_cultivo.png)

## 8. Gestión de Producción

Registra los datos de producción obtenidos en cada área de cultivo.

![Gestión de producción](imagenes/produccion.png)

## 9. Gestión de Riego

Permite programar y registrar los ciclos de riego aplicados a los cultivos.

![Gestión de riego](imagenes/riego.png)

## 10. Historial de Riego

Administra el inventario y la aplicación de agroquímicos (fertilizantes, pesticidas, etc.) en los cultivos.

Muestra indicadores del rendimiento productivo por cultivo y por área.

## 14. Reportes

El sistema ofrece varios tipos de reportes para el análisis de la producción:

| Reporte | Descripción |
|---------|-------------|
| Agroquímicos | Uso de agroquímicos por período |
| Cultivos Permanentes | Listado de cultivos de carácter permanente |
| Cultivos por Vencer | Cultivos próximos a su fecha de vencimiento |
| Fecha de Recogida | Cultivos según fecha de recogida |
| Plan de Producción | Plan de producción programado |
| Resumen de Cultivos | Resumen general del estado de los cultivos |

![Reportes](imagenes/reportes.png)
